# Shelf · The roadmap

*The concept step's roadmap, written on 2026-11-17. It rests on D2, D3, D4, D5, D6, D7, D8 and D9 ([the decisions](decisions/README.md)). The estimates are senior dev-days, not dates.*

| Milestone | Estimate | Done when |
|---|---|---|
| The MVP | 5.75 dev-days | a reader adds a book, moves it from To read to Reading and then to Finished, sees this year's count go up by one, and finds it all still there after the server restarts |
| Phase 1 | 3.25 dev-days | a reader can add a book by its ISBN and sees their books grouped under shelves in an order they set |

**The plan:** about 9 dev-days, 7.5 to 11; no dates.

## The MVP

1. M1 · Books and shelves saved on the server
2. M3 · A new Shelf starts with three shelves
3. M4 · Add a book by its title
4. M5 · Add, rename and delete shelves
5. M6 · Move a book from one shelf to another
6. M7 · Mark a shelf as the finished shelf
7. M8 · Count of books finished this year
8. M9 · Remove a book

## Phase 1

1. P1.1 · Add a book by ISBN from a book API
2. P1.2 · Books grouped by shelf
3. P1.3 · Reorder shelves
