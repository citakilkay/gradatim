# Commands

What to run in Shelf, and what each command does.

| Command | What it does |
|---|---|
| `npm run dev` | Runs the front end and the server on this machine |
| `npm test` | Runs the tests |
| `npm run build` | Builds the front end into `dist/` |
| `npm run lookup -- <isbn>` | Looks a book up on Open Library, as the app does, and prints what came back |
| `npm run deploy -- <version>` | Sends a release out, as [the runbook](../RUNBOOK.md) says |
