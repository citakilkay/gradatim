# Sprints

*The rules every sprint follows, the module codes, and the sprints. Written by the new sprint step on 2026-11-04.*

## The rules

- A sprint holds about 10 to 15 senior dev-days. The band is a guide: a sprint may stretch to 20 when the work needs it.
- A task's id is its module's code, a hyphen and the next number in that module, across all sprints, such as CAT-3.
- A sprint's board lists its tasks in the order of work, with their story, dependencies, estimate and status.
- At most one sprint is open at a time.

## Module codes

| Code | Module |
|---|---|
| `CAT` | The catalogue: the ISBN lookup and the covers |
| `SHF` | The shelves |
| `SYN` | The sync between the device and the server |
| `INF` | Infrastructure: the server, sign-in and hosting |
