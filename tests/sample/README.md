# The sample project: Shelf

*The made-up project that Gradatim's scenarios run on. Written by FND-5 on 2026-10-29. Shelf is a small web app where a reader keeps track of their books, as [the worked example](../../docs/guides/example.md) shows. Its files belong to the made-up project, not to this repository. Each name that a host or git reads, such as `AGENTS.md` or `.gitignore`, ends here in `.sample`, and the runner takes it off when it builds a state.*

## The states

A state is the project as a step left it. Its folder holds only the files that its step wrote or changed. To build a state, the runner lays the states below it first, from the one that `empty` starts, then the state's own folder, and deletes the files in its Removes cell. `empty` is built in: a folder with nothing in it.
