# 02 · The release in the footer

*Decide's second session, 2026-11-05, from the user's new direction, in their own words: "I want to see which release is running": how a reader, and whoever sends a release out, tells which release answered.*

### D10 · Every page's footer names the release

- **Decision:** every page's footer reads Shelf <version>, with the version of the release that is running. The check after a release reads the footer, and compares it with the version just sent out.
- **Over:** a page of its own for the version, which nobody opens; and the build's SHA-256 alone, which a reader can't see.
- **Why:** after a release, the runbook has the site opened and a book added, and nothing on the site says which release answered. A reader who reports a problem can then name the version too.
- **Date:** 2026-11-05.
