# Commands

What to run in Shelf, and what each command does. A command marked `planned` doesn't exist yet: the task that builds it sets its Built by to its id.

| Command | What it does | Built by |
|---|---|---|
| `npm install` | Installs the dependencies, of which there are none yet, as the project's `README.md` says | existing |
| `npm start` | Runs the app at http://localhost:3000, as the project's `AGENTS.md` says | existing |
| `npm test` | Runs the tests with `node --test`, as the project's `AGENTS.md` says | existing |
