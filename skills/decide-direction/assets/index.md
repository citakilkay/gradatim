# The decisions index

*The template of `docs/decisions/README.md`, which decide creates at its first yes. Decide and architecture each add a row for every decision they record. A decision is final once it has a row here, and its Status is `holds` or `replaced by D<n>`. The index is living, so each change is logged at its end.*
